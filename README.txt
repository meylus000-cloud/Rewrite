SONIC REWRITE — README

ПЕРШИЙ ПРОТОТИП ДЛЯ WINDOWS 10/11

Що вже працює:
- прозоре вікно персонажа без рамки;
- авторський тестовий sprite sheet;
- базова циклічна анімація;
- переміщення в межах загальної області моніторів;
- перетягування персонажа мишкою;
- системний трей;
- сон та пробудження з останнього боку екрана;
- субтитри з ефектом друкування.

Що ще НЕ реалізовано:
- справжнє розпізнавання голосу;
- озвучування відповідей;
- підключення мовної моделі;
- автоматичне читання імені Windows-користувача;
- аналіз екрана;
- повноцінне керування вікнами та файлами;
- посадка на рамки вікон та складна навігація між окремими дисплеями.

ЗАПУСК З PYTHON
1. Встановіть Python 3.11 (64-bit).
2. Відкрийте PowerShell у папці SonicRewrite.
3. Виконайте:
   py -3.11 -m venv .venv
   .\.venv\Scripts\Activate.ps1
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   python main.py

VOICE.MP3
Якщо у вас є аудіофайл із бажаним зразком голосу:
1. Зробіть копію оригінального аудіофайлу.
2. Перейменуйте копію точно на Voice.mp3 (важливі англійські літери та розширення .mp3).
3. Покладіть Voice.mp3 поруч із main.py або SonicRewrite.exe.
4. Не видаляйте оригінальний файл.
У поточному прототипі Voice.mp3 ще не використовується. Підключення зразка голосу буде реалізоване разом із голосовим модулем.

REWRITE.SAFRI
Відкрийте Rewrite.safri через Блокнот. Можна змінювати personality, greeting та додавати власні інструкції. Не вставляйте в нього API-ключі.

ЗБІРКА ЧЕРЕЗ GITHUB
1. Створіть порожній репозиторій GitHub.
2. Завантажте в репозиторій усі файли цієї папки.
3. Відкрийте вкладку Actions.
4. Виберіть Build Windows EXE та натисніть Run workflow.
5. Після успішної збірки завантажте артефакт SonicRewrite-Windows.

Безпека: не завантажуйте API-ключі, паролі чи особисті файли до відкритого GitHub-репозиторію.
