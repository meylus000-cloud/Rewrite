# Sonic Rewrite — прототип для Windows

Це перша робоча основа настільного персонажа Sonic Rewrite. Проєкт створюється поетапно: зараз реалізовані прозорий аватар, базова анімація, переміщення в межах віртуального робочого столу, системний трей, сон/пробудження та субтитри з ефектом друкування.

> Важливо: голосове розпізнавання, потокове озвучування, підключення LLM, повноцінний аналіз екрана та керування файлами/вікнами ще не реалізовані. Вони не маскуються заглушками під готові функції.

## Вимоги
- Windows 10/11, 64-bit
- Python 3.10–3.12 (рекомендовано)
- Для першого запуску потрібен інтернет лише для встановлення залежностей.

## Запуск із Python
1. Розпакуйте папку проєкту.
2. Відкрийте PowerShell у цій папці.
3. Створіть середовище:
   ```powershell
   py -3.11 -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```
4. Встановіть залежності:
   ```powershell
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```
5. Запустіть:
   ```powershell
   python main.py
   ```

## Керування прототипом
- Перетягування лівою кнопкою миші — перемістити Rewrite.
- Подвійне клацання — показати тестову репліку.
- Контекстне меню правою кнопкою — сон, пробудження, вихід.
- Значок у системному треї — ті самі команди.
- Rewrite автоматично засинає після періоду бездіяльності (налаштовується в `config.json`).

## Файли персонажа
- `Rewrite.safri` — текстова пам'ять/інструкції персонажа. Його можна редагувати Блокнотом.
- `Voice.mp3` — необов'язковий файл-зразок голосу для майбутнього модуля голосу. Просто перейменуйте власний аудіофайл на `Voice.mp3` і покладіть поруч із `main.py`. У цьому прототипі він ще не використовується.
- `README.md` — ця інструкція.

## Збірка EXE локально
```powershell
pip install pyinstaller
pyinstaller --noconfirm --clean --windowed --name SonicRewrite --add-data "assets;assets" main.py
```
Готовий файл буде в `dist\SonicRewrite\SonicRewrite.exe` (або в `dist\SonicRewrite.exe`, залежно від режиму PyInstaller).

## Збірка через GitHub Actions
1. Створіть порожній GitHub-репозиторій.
2. Завантажте в нього вміст цієї папки.
3. Відкрийте вкладку **Actions** і запустіть workflow **Build Windows EXE** через **Run workflow**.
4. Після завершення відкрийте запуск workflow та завантажте артефакт `SonicRewrite-Windows`.

Для API-ключів майбутніх сервісів використовуйте змінні середовища або локальний файл налаштувань, який не додається до Git. Не публікуйте ключі у відкритому репозиторії.
